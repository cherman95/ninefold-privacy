# Ninefold privacy policy

The privacy policy for the Ninefold Android app (com.eurekadigilabs.ninefold), served by GitHub Pages at
https://cherman95.github.io/ninefold-privacy/ . `ads-config.json` is the remote ads kill switch the app fetches
(values can only tighten the built-in limits).

Edited from `docs/privacy-site/` in the game repo.
